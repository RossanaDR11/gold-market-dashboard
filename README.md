Gold Market Analysis Dashboard
This project presents a Power BI dashboard analyzing the gold market, focusing on price performance, technical indicators, and risk metrics.

The goal of this dashboard is to provide a clear overview of how gold behaves as a financial asset by combining market data with data visualization techniques.

Dashboard Features
The dashboard is structured into two main sections:

1. Market Overview
Current gold price
Daily change
RSI indicator (momentum signal)
Historical performance (YTD, long-term returns)
Moving averages (MA50 and MA200) to identify market trends
2. Risk Analysis
Volatility metrics
All-Time High price
10-Year Low price
Volatility visualization to highlight periods of market uncertainty
Tools Used
Power BI Desktop
Financial time-series data
DAX measures for performance and risk metrics
Collaboration
This project was developed in collaboration with Rossana De Rose, focusing on financial data analysis and dashboard design.

File
The dashboard is available as a .pbix file and can be opened using Power BI Desktop.
